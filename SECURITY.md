# Security Policy

Do not report vulnerabilities in public issues.

Use GitHub's private vulnerability reporting feature for
`nicosmuts/helm-charts` when it is enabled. If it is unavailable, contact the
maintainer privately through the contact information on the
[maintainer's GitHub profile](https://github.com/nicosmuts).

Include the affected chart and version, impact, reproduction details, and any
suggested mitigation. Reports will be acknowledged and triaged as maintainer
availability permits. Supported chart versions and remediation details will
be stated in each security advisory.

See [docs/SECURITY.md](docs/SECURITY.md) for chart authoring and supply-chain
requirements.
